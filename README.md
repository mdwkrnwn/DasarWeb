# Desain dan Pemrograman Web

Repository ini digunakan untuk menyimpan **source code hasil praktikum** mata kuliah **Desain dan Pemrograman Web** pada Semester 3.

Praktikum mencakup pembelajaran dan implementasi dasar hingga pengembangan aplikasi web menggunakan teknologi **front-end** dan **back-end**.

## 🛠️ Teknologi yang Digunakan

* **HTML5** — struktur dan konten halaman web
* **CSS3** — styling dan responsive design
* **JavaScript** — interaktivitas dan manipulasi DOM
* **PHP Native** — pemrograman sisi server
* **PostgreSQL** — basis data
* **Laragon** — development environment
* **Git & GitHub** — version control dan penyimpanan source code

## 📁 Isi Repository

Repository ini berisi source code praktikum yang dikerjakan selama perkuliahan, meliputi:

* Struktur halaman menggunakan HTML5
* Styling menggunakan CSS3
* Responsive Web Design
* JavaScript, DOM, dan event handling
* AJAX / Fetch API dan JSON
* PHP dan pengolahan form
* Koneksi PHP dengan PostgreSQL
* CRUD
* Autentikasi dan session
* Dasar keamanan web
* Integrasi front-end dan back-end

## 🎯 Tujuan

Repository ini dibuat sebagai **dokumentasi source code dan hasil pengerjaan praktikum** selama mengikuti mata kuliah Desain dan Pemrograman Web.
