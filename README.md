## 🛠️ Teknologi yang Digunakan

- **HTML5** — struktur dan konten halaman web
- **CSS3** — styling dan tampilan halaman web
- **JavaScript** — interaktivitas dan manipulasi halaman web
- **PHP Native** — pemrograman sisi server
- **PostgreSQL** — basis data
- **Laragon** — development environment
- **Git & GitHub** — version control dan penyimpanan source code

## 📖 Materi Praktikum

Repository ini digunakan untuk menyimpan source code yang dikerjakan selama perkuliahan, di antaranya:

- Struktur dasar HTML
- Heading dan paragraf
- Formatting teks
- Link dan navigasi
- List
- Gambar
- Tabel
- Form
- CSS dan styling
- JavaScript
- Pemrograman sisi server menggunakan PHP
- Pengolahan data dengan PostgreSQL
- CRUD
- Autentikasi dan session
- Integrasi front-end dan back-end

> Daftar materi akan diperbarui sesuai dengan praktikum dan jobsheet yang telah dikerjakan.
